# Cyber Nekova · emails a todos los suscriptores

Promoción: **20% OFF en toda la tienda**, del lunes 2/11/2026 a las 00:00hs al viernes 6/11/2026 a las 23:59hs (el CyberMonday oficial termina el miércoles 4; Nekova lo extiende hasta el viernes). El descuento es automático: no hay código.

## Cómo programarlos (Shopify Email)

Shopify → **Marketing → Campañas → Crear campaña → Shopify Email** → plantilla en blanco o "Promoción".

- **Destinatarios:** el segmento **"Suscriptores de marketing por email"** (o "Email subscribers"). Incluye a todos los que aceptaron recibir emails, con cualquier etiqueta: footer, lista de lanzamiento, Cyber Nekova y compradores.
- **Remitente:** Nekova (info@nekova.com.ar).
- **Botón:** a `https://www.nekova.com.ar/collections/all`.
- **Imagen:** `marca/shopify/coleccion-productos.jpg` (los productos juntos) o la del producto que quieras destacar.
- Enviate una **prueba** antes y después tocá **Programar** con la fecha y hora de cada email.
